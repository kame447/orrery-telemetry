## 変更内容

- registration side effect より前に、target work_dir と selected project namespace の組を current project-context resolver で検証します。
- physical project key は同一 repository / non-Git root だけを受け入れます。logical namespace は launcher が渡した repository/workspace provenance と一致する場合だけ受け入れます。
- reserved identity は、validated target project に同名 identity が既に存在することを tokenless `whois` で確認してから進みます。
- owner token は `whois` には渡しません。current bundled Mail の published `whois` schema は `registration_token` を受け取らないためです。
- owner token の真正性は、その後の `register_agent` に token を渡し、既存 row の atomic credential check に任せます。これにより foreign-project token で target project に同名 identity を新規作成する経路を閉じつつ、current Mail schema を維持します。
- SessionStart は inherited `PWD` ではなく hook payload の `cwd` を project resolution / registration work_dir の authority として使います。
- identity/session fixtures を current project-context と current Mail schema に追従させ、cross-project registration が mutation 前に fail closed する regression を追加しています。
