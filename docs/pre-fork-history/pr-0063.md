## 目的

Closes kame447/orrery-telemetry#33

child 起動時の OS terminal 自動表示を、tmux session と Deck の Open tmux から独立して切り替えられるようにする。

upstream #87 の maintainer 方針に合わせ、`AGENTSTACK_AUTO_OPEN_CHILD=1` を製品既定として維持する。Dashboard 中心の利用者は `0` にすると、自動表示だけを止めて Deck の Open tmux を残せる。

## 変更範囲

- 自動表示入口だけに `AGENTSTACK_AUTO_OPEN_CHILD` の gate を追加
- `AGENTSTACK_TERMINAL` は terminal adapter の選択として維持
- installer で 0 / 1 を検証し、再インストール時も保存値を保持
- `env.sh`、install-state、launchd、systemd、background serviceへ伝播
- 新規 Claude / Codex child と Codex resume 先へ設定を伝播
- `AGENTSTACK_FOCUS_CHILD=1` は自動表示された window の前面化だけを担当
- README / configuration を日英で更新
- Gemini の別 launcher、Mail、identity、reservation、readiness、history binding は変更しない

## upstream との関係

提案: https://github.com/gyroid-eth/orrery-telemetry/issues/87

maintainer から「自動表示を独立設定に分けることには賛成。ただし既定はONを維持したい」と回答があったため、当初の fork-only 既定OFF案を撤回し、既定ONへ合わせた。
