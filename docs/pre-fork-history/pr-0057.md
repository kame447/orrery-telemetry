Closes kame447/orrery-telemetry#28

2026-09-23 の fresh dependency resolution で SQLModel 0.0.46 が入り、current master `a9260cc28f6bb39cc47b7aac706920fce560a6c6` の macOS Python 3.11 / 3.12 / 3.14 CI が一斉に失敗する baseline regression を修正します。

9/19 の green run は SQLModel 0.0.42、9/23 の failed run は 0.0.46 を解決しています。SQLModel 0.0.45 では plain `datetime` field が UTC-aware storage に変更され、naive database parameter を拒否する breaking change が入りました。

一方、AgentStack Mail は `models.py::_utcnow_naive()` で SQLite compatibility と ORM evaluator の比較整合性のため naive UTC を current contract として明示しています。UTC-aware migration は既存DB、datetime producer、query/comparisonまで含む別の migration unit になるため、この修正には含めません。

変更は2ファイルだけです。

- `packages/agentstack_mail/pyproject.toml`: `sqlmodel>=0.0.16,<0.0.45` に制約し、migration まで pre-0.0.45 contract を固定
- `packages/agentstack_mail/tests/verify_artifact.py`: built distribution metadata に同 constraint が残ることを検証

Phase 1–3 project isolation とは独立した prerequisite です。これが green になった後、同じ commit を Phase 1 → Phase 2 → Phase 3 へ通常 merge で伝播し、それぞれの固有差分を再確認します。
