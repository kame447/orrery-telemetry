## 概要

upstream `gyroid-eth/orrery-telemetry#33` の Phase 7b1 として、Dashboard が live tmux session を現在の project に帰属できるか判定する primitive だけを追加します。

## 変更内容

- filesystem project key を canonical repository identityへ解決する `_canonical_dashboard_project_key()` を追加
- shared `project-context.sh` resolver を利用する context helper群を追加
- durable ownership metadata（name binding / token project sidecar / child state）のproject一致を検証
- tmux session の `AGENTSTACK_PROJECT_KEY` / `PROJECT_KEY`、repository/work-dir、live cwdを組み合わせて `_session_matches_dashboard_project()` でfail-closed判定
- durable metadataが壊れている・競合している場合は `_DURABLE_PROJECT_CONFLICT` として拒否
- legacy sessionはproject keyがなくても、verified cwdが現在projectに一致する場合だけ帰属可能
- `_live_session_matches_dashboard_project()` / `_live_session_conflicts_with_dashboard()` を追加
- token `.project` sidecarはsymlinkを追わず、legacy absence (`None`) とinvalid/unreadable (`""`) を区別
