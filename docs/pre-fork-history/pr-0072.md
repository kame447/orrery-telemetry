## 目的

Issue kame447/orrery-telemetry#35。Dashboard NEW AGENT の Antigravity / Gemini モデル一覧を、ローカル `agy models` に自動追従させます。実機では `gemini-4-argon-{low,medium,high}` の検出を確認しています。

## 変更内容

- 従来の `gemini-3.8-flash` 3候補を維持し、CLI から発見した Gemini 候補を追加。他プロバイダーの ID・不正な形式・重複を除外します。
- モデル探索は最大5秒・64 KiBとし、正常結果を5分キャッシュ。一時失敗時は成功済み候補を保持して5秒後に再試行。同時アクセスでも重複した探索を行いません。
- 候補表示と起動許可を分離。明示的な `AGENTSTACK_GEMINI_MODELS` の許可リストは優先し、それ以外の正式な `gemini-*` IDはCLIに最終判断を委ねます。spawn / dry_run では `agy models` を実行しません。
- モデルごとの実在する effort のみ UI に提示し、選択された正式 ID を登録・起動へ一貫して引き渡します。
- CLIを起動しうる `/api/spawn-names` へ `/api/quotas` と同じブラウザーのsame-origin検査を追加。ローカルの通常のCLIクライアントは維持。
- 日英ガイド、変更履歴、回帰テストを更新。新しい外部依存や稼働中runtimeの切替はありません。

## 検証

fork master `5656790` へ追従済み。最新 HEAD `e296915` に対する GitHub Actions PR workflow [#39549358644](https://github.com/kame447/orrery-telemetry/actions/runs/39549358644) が全件成功。
