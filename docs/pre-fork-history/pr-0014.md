~~~~markdown
Closes kame447/orrery-telemetry#14

Dashboard の DECK 上部に Claude / Codex / Antigravity のアカウント quota 残量を表示します。各 agent の context remaining とは別の表示です。

## 現在の表示と取得

Claude → Codex 通常枠 → Antigravity の固定順で、主要領域は画面幅に応じて3列・2列・1列へ折り返します。同じ Codex 利用枠の window は隣接させ、短い順に表示します。通常枠を取得できない場合に別の追加枠を通常枠へ昇格させません。

GUI 確認後のユーザー指示により、Spark と Antigravity 内の Claude / GPT quota は表示対象から外しました。非表示にするのは UI のみで、API の bucket は保持します。独立した Claude / Codex の通常枠、Antigravity の Gemini 枠と未知の枠は残し、未知の Codex limit ID は追加情報へ表示します。追加表示対象が空なら ADDITIONAL LIMITS の領域全体を隠します。提供終了日の推測に基づく削除ではありません。

reset 日時はブラウザのローカル時刻で `9/19 21:18 reset` の形式を常時表示します。欠損値は UNKNOWN とし、残量や日時を推定しません。追加情報に横スクロールが必要な場合は、左右矢印と edge fade を表示し、端・resize・DECK / NETWORK 切替に追従します。

Claude は opt-in の statusLine observer、Codex は App Server `account/rateLimits/read`、Antigravity は明示 opt-in の read-only usage を使用します。既存 Claude statusLine は上書きしません。

provider 別の lock / TTL / cache と独立した GET /api/quotas を追加しています。600秒の観測期限、未来時刻、reset 後の stale を検査し、未観測値を作りません。任意の例外本文や認証情報を API / log に出しません。quota wrapper は既存の agents / mail / tmux / spawn / exit を既存 server に委譲し、常駐起動と agentctl.sh fg の両方で動作します。元ページの script を保持して UI を挿入し、NETWORK では quota を隠し、served demo は実 API 通信を遮断します。

upgrade installer は検証済みの稼働中 Mail render を adopt してから AGENTSTACK_MAIL_ENV を検査します。既存 install 由来の一致値は受け入れ、明示的な空値・異なる値は引き続き拒否します。実 runner / controller pidfile / installed env.sh を使う回帰テストを追加済みです。

## 観測時刻の追加修正

Claude を使っていない間は受動的な観測が更新されず、正常な設定でも期限切れになります。期限切れのたびに observed_at を現在時刻へ置き換える問題を修正し、最後の有効な観測時刻 last_observed_at と、取得試行の最終完了時刻 checked_at を分離しました。未観測時の last_observed_at は null です。再起動後も有効な保存済み観測の時刻を保持しますが、期限切れの残量は返しません。

UI は WAITING FOR UPDATE と最終観測からの経過時間を表示します。新しい有効な観測が来れば既存の cache / polling 周期で復帰します。期限の延長、時刻だけの書換え、認証操作、statusLine の上書き、自動会話は行いません。
~~~~
