### ChatGPT 用 MCP から既存エージェントへ ORRERY Mail で追加指示を送れるようにした（既定オフ）

`orrery-chatgpt-mcp` に `orrery_message_preview` / `orrery_message_commit` / `orrery_message_status` を追加しました。送信者は運用者が `agentstack-daemon create --operator` で作る専用の `orrery-daemon` identity で、エージェントの owner token は借りません。宛先はその daemon プロファイルに運用者が書いた名前と数値 Mail ID の組だけです。送信の直前ごとに Mail インスタンス UUID、送信者の行と credential、宛先の ID・プロジェクト・退役状態・program を照合し、名前の再利用や退役は送らずに拒否します。本文の制御文字・不可視文字はプレビューで拒否し、コミットにはプレビューの内容ハッシュと idempotency key が必要です。記録は再起動後も有効で、結果不明は再送せず Mail の表示と照合します。1 時間あたりの上限、本文を含まない監査記録、Mac 上での承認モードがあります。daemon helper をゲートウェイの Python（SQLAlchemy なし）で読めるよう、管理ソケットの定数を `agentstack_mail.enrollment_protocol` に分けました。launchd 常駐版では送信は無効のままです。実際の ChatGPT からの送信は未確認です。[docs/chatgpt-mcp-message.md](../docs/chatgpt-mcp-message.md)
