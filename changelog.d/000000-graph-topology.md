### コックピット向けに通信と親子関係を軽量に取得できるようにしました

API 世代を47から48へ更新し、legacy / fresh の `/api/graph?topology_only=1` でノード詳細を計算せず、親子関係と通信の接続先を返します。通信の接続と直近90秒の活動表示を分けて扱えます。既存の通常 graph、`spawn_only`、表示期間、認可範囲は変わりません。

再開後に tmux の親情報が欠けた child は、現在の登録に一致する保存済み起動記録から親子関係を復元します。dsh / Hermes の standalone は、本人照合した起動入力が無親を明示している場合に通信相手を親と誤認しなくなります。親の記録が欠けただけの row は standalone と断定しません。
